# C++ - Module 01

> Memory allocation, pointers to members, references and switch statements  
> Version: 10.1

---

## Description

This module deepens C++98 fundamentals, focusing on memory management, the use of pointers, references, and pointers to member functions. It also introduces `switch` and takes a more object-oriented approach than the previous module, still without using the STL

---

## Main Objectives

- Understand the difference between **stack** and **heap** allocation
- Use **pointers**, **references**, and manually manage memory
- Dynamically create and destroy objects without memory leaks
- Automate method calls via **pointers to member functions**
- Use the **switch statement** effectively
- Strengthen rigor in dependency management (`#include`) and object-oriented code structure

---

## Compilation

Use:

c++ -Wall -Wextra -Werror -std=c++98 main.cpp
