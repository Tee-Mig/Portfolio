# Regression lineaire Prediction du prix des voitures

Implementation simple dune regression lineaire entrainee avec gradient descent pour predire le prix dune voiture en fonction de son kilometrage

## Objectif

- Implementer une regression lineaire from scratch
- Entrainer un modele avec gradient descent
- Normaliser les donnees dentree
- Comprendre la convergence du modele

## Modele

Le modele predit le prix dune voiture a partir du kilometrage avec deux parametres

- theta0 intercept
- theta1 pente

## Entrainement

- Le kilometrage est normalise
- La fonction de cout est basee sur lerreur quadratique moyenne
- Les parametres sont mis a jour avec gradient descent
- Larret se fait lorsque le cout converge

## Resultat

- Les parametres appris sont sauvegardes
- Visualisation des donnees et de la droite de regression
- Suivi de levolution du cout et des gradients

## Technologies

- Python
- Pandas
- Matplotlib
