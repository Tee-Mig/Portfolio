# Product Sales Dashboard — Power BI

Dashboard Power BI orienté **pilotage de la performance commerciale**.

Projet conçu comme un **cas BI réaliste d’entreprise**, avec modélisation en étoile, mesures DAX et visualisations décisionnelles.

---

## Objectifs

- Suivre les **ventes et la rentabilité**
- Analyser les **tendances temporelles** (WOW / MOM / QOQ)
- Identifier les **contributeurs clés** (SalesPerson, Team, Category)

---

## Modèle de données

- **fct_Shipments** : faits de vente
- **dim_Date** : calendrier
- **dim_People** : commerciaux / équipes
- **dim_Products** : produits / catégories
- **Time Intelligence** : table déconnectée (WOW / MOM / QOQ)

---

## Indicateurs clés (DAX)

- **Sales**, **Profit**, **Profit %**
- **Sales Change %** : évolution vs période précédente
- **Sales Contribution %** : poids dans le total des ventes

---

## Visualisations

- KPI Cards (Sales, Profit, Profit %)
- Line chart : évolution des ventes
- Table SalesPerson : volume, évolution et contribution
- Bar charts : ventes par catégorie et par équipe

---

## Interactivité

- Date Range
- Sélecteur WOW / MOM / QOQ
- Slicers produits et commerciaux

---

## Compétences démontrées

- Power BI Desktop
- DAX (Time Intelligence, ratios)
- Modélisation BI
- Data visualisation orientée décision
