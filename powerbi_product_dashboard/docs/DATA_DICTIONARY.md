# Power BI Product Sales Dashboard — Dataset

## Tables

- `dim_Date` : calendrier (Date, Year, Quarter, Month, WeekStart, …)
- `dim_Products` : produits + `CostPerBox` (pour calculer Profit)
- `dim_People` : commerciaux + Team + PictureUrl (placeholder)
- `dim_Locations` : Geo/Region
- `fct_Shipments` : expéditions (Boxes, Sales) + clés
